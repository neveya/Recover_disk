# Disk Recover Tool

NTFS · FAT12/16/32 · exFAT 디스크 이미지와 드라이브에서 **파일 목록(폴더 구조 포함)을 읽고, 삭제되었거나 손상된 파일을 다른 디스크로 복사(복구)**하는 읽기 전용 도구입니다.

> **⚠️ 먼저 읽어 주세요**
> - 이 프로그램은 **무료로, 있는 그대로(AS IS), 어떠한 보증도 없이** 제공됩니다. 사용으로 생기는 모든 문제(데이터 손실 포함)의 책임은 사용자에게 있습니다. 자세한 내용은 [DISCLAIMER.md](DISCLAIMER.md)와 [LICENSE](LICENSE)를 보세요.
> - **복구한 파일은 반드시 '다른 디스크'에 저장하세요.** 복구하려는 드라이브에 쓰면 삭제된 데이터가 영구히 덮어쓰입니다.
> - 중요한 데이터이거나 디스크에서 소리가 나거나 인식이 불안정하다면, **사용을 멈추고 전문 복구 업체에 문의하세요.** 불량 디스크를 계속 읽으면 상태가 더 나빠질 수 있습니다.
> - 본인 소유이거나 접근 권한이 있는 저장장치에만 사용하세요.

## 1. 주요 기능

- 디스크 이미지(`.dd` `.img` `.raw` `.001` 분할 이미지, E01은 선택 설치 필요) 또는 **드라이브/물리 디스크를 읽기 전용으로** 열어 파일·폴더 목록 출력
- 삭제된 파일과 폴더도 목록에 표시
- 파일마다 **정상 / 의심 / 손상추정** 판정(메타데이터 검사, 선택적으로 파일 앞부분 시그니처 확인)
- 폴더 단위로 골라서 **원래 폴더 구조 그대로 복사**, 복사 진행률(경과/예상 시간, 용량, %) 표시, 결과 보고서(CSV) 저장
- `--root` 로 **특정 경로 아래만** 목록·확인·복구
- 손상이 심한 NTFS(`$MFT` 일부 소실 등)를 위한 스캔 모드, 루트 폴더가 손상된 FAT 의 유실 폴더 탐색

## 2. 지원 범위와 한계

| 항목 | 지원 |
|---|---|
| 파일시스템 | NTFS, FAT12/16/32, exFAT |
| 입력 | raw 이미지, 분할 이미지(.001), E01(선택), 드라이브(`E:`), 물리 디스크(`\\.\PhysicalDriveN`), Linux 블록 장치 |
| 운영체제 | Windows 10/11 (주 대상), Linux (`sudo`). macOS는 미지원/미검증 |
| 파티션 | MBR, GPT(백업 헤더 포함). 표가 없으면 부트섹터를 직접 탐색 |

**지원하지 않거나 한계가 있는 것**

- **암호화된 볼륨**: BitLocker 등으로 암호화된 상태의 디스크를 물리 디스크로 읽으면 암호문이 읽혀 복구할 수 없습니다. 잠금이 풀린 상태의 드라이브 문자(`C:`)로 열거나, 복구 키로 잠금을 푼 뒤 사용하세요.
- NTFS **압축 파일**, **EFS 암호화 파일**은 복사하지 않습니다(목록에는 표시).
- ext4, APFS, HFS+, ReFS 등 다른 파일시스템은 지원하지 않습니다.
- **SSD**는 삭제 직후 TRIM으로 내용이 지워지는 경우가 많아, 목록에는 있어도 내용이 비어 있을 수 있습니다.
- **FAT/exFAT에서 삭제된 파일**은 클러스터 연결 정보가 지워지므로 "연속 저장"을 가정해 복구합니다. 조각났던 파일은 내용이 어긋날 수 있어 **의심**으로 표시됩니다.
- 복구 가능성은 삭제 후 해당 드라이브에 쓰기가 얼마나 있었는지에 크게 좌우됩니다. **복구를 보장하지 않습니다.**

## 3. 요구 사항

| 항목 | 내용 |
|---|---|
| Python | **3.10 이상** 권장 (개발·테스트: 3.11, 3.12, 3.13). exe 버전을 쓰면 Python 설치 불필요 |
| 추가 패키지 | **없음** (표준 라이브러리만 사용) |
| 선택 패키지 | E01 이미지를 읽으려면 `libewf-python` (`import pyewf`). 빌드하려면 `pyinstaller` |
| 권한 | 이미지 파일: 일반 권한 / 드라이브·물리 디스크: **관리자 권한** (Windows) 또는 `sudo` (Linux) |
| 저장 공간 | 복구한 파일을 저장할 **별도 디스크** (복구 대상 용량 이상 권장) |
| 콘솔 | Windows Terminal 또는 cmd (색상은 Windows 10 이상에서 자동 활성화) |

## 4. 설치

### 방법 A. 실행 파일(exe) — Python 불필요

1. [릴리스 페이지]에서 `DiskRecover-버전.zip` 을 내려받습니다. 내려받은 파일의 SHA-256 해시가 릴리스 페이지에 적힌 값과 같은지 확인하세요.
2. **복구할 드라이브가 아닌 곳**(USB 등)에 압축을 풉니다.
3. 드라이브/물리 디스크를 읽으려면 `DiskRecover.exe` 를 **관리자 권한으로 실행**합니다.

> 일부 백신이 PyInstaller로 만든 exe를 오진할 수 있습니다. 걱정되면 아래 방법 B(소스 실행)를 쓰거나, 소스를 직접 확인한 뒤 직접 빌드하세요.

### 방법 B. 소스 코드 실행

1. Python 3.10 이상을 설치합니다 (https://www.python.org/downloads/ — 설치 화면에서 *Add python.exe to PATH* 체크).
2. 버전을 확인합니다.
   ```
   py -3 --version
   ```
3. `disk_recover_tool.py` 를 내려받아 **복구할 드라이브가 아닌 곳**에 둡니다.
4. 실행해 봅니다.
   ```
   py -3 disk_recover_tool.py --help
   ```
5. (선택) E01 이미지를 읽을 때만:
   ```
   py -3 -m pip install libewf-python
   ```

### 방법 C. 직접 빌드 (개발자용)

```
py -3 -m pip install pyinstaller
py -3 -m PyInstaller --onedir --uac-admin --name DiskRecover disk_recover_tool.py
```

- `--onedir` 를 권장합니다. `--onefile` 은 실행할 때 C: 의 임시 폴더에 압축을 풀기 때문에, **C: 드라이브를 복구하는 상황에서는 삭제된 데이터를 덮어쓸 수 있습니다.**
- `--uac-admin` 은 실행할 때 관리자 권한을 요청합니다. `--noconsole` 은 쓰지 마세요(콘솔 프로그램입니다).
- 결과물은 `dist\DiskRecover\` 폴더입니다. 폴더째 압축해 배포하세요.

## 5. 복구 전 안전 수칙

1. **지금 당장 해당 드라이브 사용을 멈추세요.** 새로 저장되는 모든 파일이 삭제된 데이터를 덮어쓸 수 있습니다.
2. **복구한 파일은 다른 디스크에 저장**하세요. (도구는 읽고 있는 디스크와 같은 디스크에 저장하려 하면 막습니다.)
3. 이 프로그램도 **복구할 드라이브가 아닌 곳(USB 등)에서 실행**하세요. 설치/내려받기도 해당 드라이브에 하지 마세요.
4. 가능하면 **디스크 전체를 이미지로 먼저 만들고**(FTK Imager 등) 이미지로 작업하세요.
5. 가능하면 해당 디스크를 **오프라인**(Windows 디스크 관리) 또는 읽기 전용으로 바꾼 뒤 읽으세요.
6. 시스템 드라이브(C:)는 사용 중에 계속 쓰기가 발생합니다. 가능하면 다른 PC에 연결하거나 부팅 USB / Windows 복구 환경에서 작업하세요.
7. 불량 징후(이상한 소리, 느려짐, 인식 끊김)가 있으면 읽기를 멈추고 전문 업체에 문의하세요.

## 6. 사용법

### 6-1. 가장 간단한 방법 — `--browse`

```
py -3 disk_recover_tool.py E: --browse
py -3 disk_recover_tool.py D:\backup\disk.001 --browse
py -3 disk_recover_tool.py \\.\PhysicalDrive1 --partition 1 --browse
```

대화형 화면에서 폴더를 이동하고 선택한 뒤 `copy` 를 입력하면 저장 경로를 묻고 복사합니다. 복사가 끝나면 목록으로 돌아와 이어서 다른 폴더를 복구할 수 있습니다.

| 명령 | 설명 |
|---|---|
| `cd N`·`cd ..`·`cd /` | 폴더 이동 |
| `s N`·`s .`·`s all`, `u N` | 선택 / 해제 (`s r3`, `s r1-r20` 은 검색·조회 결과 번호) |
| `x 경로`, `sel`, `clear` | 제외 / 선택 목록 / 선택 비우기 |
| `ls [쪽]` | 이 폴더의 항목만 (하위 폴더 내용은 포함하지 않음) |
| `ls -r` | 하위 폴더의 파일까지 폴더별로 묶어서 |
| `find 글자` | 이름·경로 검색 (이 폴더 아래) |
| `bad` | 손상추정 파일 |
| `recent [일수]` | 삭제된 파일을 삭제 추정 시각(NTFS는 MFT 변경 시각) 역순으로. FAT/exFAT은 수정 시각 기준 |
| `usn [일수] [글자]` | NTFS 변경 저널(`$UsnJrnl`)의 삭제·휴지통 이동 이벤트(최신순). 복구 후보가 있으면 `-> r번호` 표시 |
| `rs` | 직전 결과 다시 보기 |
| `copy`, `q` | 복사 시작(저장 위치를 목록에서 선택) / 종료 |

**공통 옵션** (보기 명령 전부 동일): `-a` 쪽 나누지 않고 전부 보기 / `-r` 하위 폴더 포함(`ls`) / `-w` 볼륨 전체 기준(`ls -r`, `find`, `bad`, `recent`, `usn`). 예전 이름 `ll` 은 `ls -r` 과 같습니다.

`usn` 참고: 저널은 오래된 기록이 순환하며 지워지고, 꺼져 있거나 이미 덮어쓰였을 수 있습니다. 이벤트가 있어도 파일 내용이 살아 있다는 뜻은 아닙니다.
